# 안전보건 문서관리 서버

## 착공 준비 1차 버전

기존 실행양식·평가자료 화면 위의 **착공 준비** 메뉴에서 발주처 미팅을 시작합니다.
질문별 답변·확인상태·메모를 저장하고, 저장된 미팅의 **이어서 작성**으로 다시 접속할 수 있습니다.
검증용 질문 8개 중 동시작업 상세 질문은 선행 질문에 **예**로 답변을 저장하면 표시됩니다.
질문은 SQLite 질문 마스터에서 조회하며, JavaScript/Python에 질문 문장을 넣지 않습니다.

- 신규 파일: `storage/preparation/`에 UUID 이름으로 저장(최초 첨부 시 생성)
- 첨부 허용: JPG·PNG·WEBP·PDF, 파일당 15MB
- 답변 저장: 명시적 저장 방식. 저장 전 브라우저를 닫으면 해당 변경은 보관되지 않습니다.
- 문답 완료: 표시된 질문의 저장 완료를 의미하며, 쟁점 해결이나 착공 승인을 의미하지 않습니다.
- 나머지 단계: 준비중 화면. 미확인·쟁점사항은 답변과 연결된 목록 제공
- 기존 서버가 실행 중이었다면 종료 후 다시 시작하고 브라우저를 새로고침하세요.

자세한 API·DB·테스트·제한사항: [착공 준비 1차 구현 보고](PREPARATION_V1.md)

### DB 마이그레이션과 백업

서버 시작 시 `preparation.service.migrate()`가 기존 DB를 SQLite backup API로
`data/backups/preparation_v1_날짜_시각_식별자.db`에 백업하고 무결성을 확인한 뒤,
신규 테이블 7개와 검증용 질문을 하나의 트랜잭션으로 설치합니다.
이미 설치되어 있으면 아무것도 변경하지 않습니다. 일부 테이블만 존재하면 중단합니다.
기존 테이블과 데이터를 삭제하거나 초기화하지 않습니다.

마이그레이션 전 백업은 DB만 포함합니다. 운영 중 전체 백업은 서버를 종료한 뒤
`data`와 `storage`를 함께 보관하세요. 복구 시에도 서버를 종료하고 현재 자료를 별도 보관한 뒤
선택한 DB·파일 백업을 일치하는 시점으로 복원해야 합니다.

질문 마스터 편집 화면은 아직 없습니다. 질문 변경은 백업 후 검토된 SQL 마이그레이션으로 관리합니다.
최초 설치 SQL을 편집해도 이미 설치된 DB에 자동 재적용되지 않습니다.
답변이 있는 질문의 의미·선택지·조건을 바꾸는 정식 질문 교체는 기존 질문을 보존하고
새 question_code를 발급하는 후속 마이그레이션으로 진행하세요.

## 실행

1. `start_server.bat`을 실행합니다.
2. 브라우저에서 `http://127.0.0.1:8080`을 엽니다.
3. 같은 사내망의 다른 PC에서도 접속해야 할 때만 `start_server_lan.bat`을 사용합니다.

## 저장 위치

- DB: `data/risk_management.db`
- 현재 파일: `storage/forms`, `storage/evidence`
- 교체 파일 이력: `storage/versions`

파일을 교체하면 기존 파일을 삭제하지 않고 새 버전으로 보관합니다. 문서 상태, 점수, 비고, 공통정보 변경사항은 SQLite DB에 즉시 저장됩니다.

실행양식 이름을 클릭하면 양식별 입력화면이 열립니다. 입력기록은 여러 건을 누적할 수 있으며 조회, 수정, 삭제할 수 있습니다.

## 백업

서버를 종료한 뒤 `data`와 `storage` 폴더를 함께 복사하면 전체 자료를 백업할 수 있습니다.

## 주의

`start_server_lan.bat`은 사내망에서 접속할 때만 사용합니다. 현재 버전에는 사용자 로그인 기능이 없으므로 인터넷에 직접 공개하지 마세요.
